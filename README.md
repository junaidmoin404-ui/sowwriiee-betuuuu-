# Birthday Surprise — GitHub Pages

## Current assets
- 3 photos are included as `photos/photo1.jpg` through `photo3.jpg`.
- Add `photo4.jpg` and/or `photo5.jpg` if you later want more photos.
- The website expects an audio file named exactly `song.mp3`.

## Audio timing
The JavaScript starts the audio at **137 seconds (02:17)** and stops it at **177 seconds (02:57)**. It does not loop the audio.

Because the Spotify URL cannot be packaged as an MP3, this ZIP does not contain a Spotify-derived audio file. Put your legally obtained audio file in the project root and rename it to `song.mp3`.

## GitHub Pages
1. Create a **Public** GitHub repository.
2. Extract this ZIP.
3. Upload `index.html`, `style.css`, `script.js`, `song.mp3`, and the `photos` folder.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Branch: **main**; folder: **/(root)**.
7. Click **Save**.
8. Open the generated GitHub Pages URL.

No custom domain is needed.
